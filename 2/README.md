
| Выражение | Ручной прогноз | Результат Python | Объяснение |
| :--- | :---: | :---: | :--- |
| `2 + 3 * 4` | 14 | 14 | Умножение имеет более высокий приоритет, чем сложение: сначала `3 * 4 = 12`, затем `2 + 12 = 14`. |
| `(2 + 3) * 4` | 20 | 20 | Скобки меняют порядок действий: сначала выполняется сложение `2 + 3 = 5`, затем `5 * 4 = 20`. |
| `17 // 5` | 3 | 3 | Целочисленное деление отбрасывает дробную часть ($17 / 5 = 3.4 \rightarrow 3$). |
| `17 % 5` | 2 | 2 | Остаток от деления $17$ на $5$ равен $2$ ($17 = 5 \times 3 + 2$). |
| `-7 // 2` | -4 | -4 | Целочисленное деление в Python всегда округляет результат в меньшую сторону (к целому значению, лежащему левее на числовой прямой): $-7 / 2 = -3.5 \rightarrow -4$. |
