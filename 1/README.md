## 2. Теоретические объяснения

1. **Различие между строками и числами:**
   - **Строка (`str`)** — это последовательность символов в кавычках (`"2"`, `"hello"`). Оператор `+` для строк делает конкатенацию (склеивание): `"2" + "3"` превратится в `"23"`.
   - **Числа (`int`, `float`)** — это математические величины. Оператор `+` для чисел выполняет арифметическое сложение: `2 + 3` превратится в `5`.

2. **Порядок вычислений:**
   - В Python математические операции имеют стандартный приоритет: сначала выполняется умножение и деление, затем сложение и вычитание. 
   - Для изменения порядка вычислений используются круглые скобки `()`. Например, в `(a + b + c) / 3` скобки гарантируют, что сначала найдется сумма, а затем результат разделится на 3.

3. **Назначение временной переменной при обмене (`swap`):**
   - Чтобы поменять местами значения двух переменных без их потери, нужна треть временная переменная (`temp`). Она выступает в роли промежуточного буфера, куда «сохраняется» значение первой переменной перед тем, как перезаписать в неё значение второй.

4. **Форматирование денежного вывода (`:.2f`):**
   - Запись `:.2f` форматирует число с плавающей точкой (`float`), оставляя ровно 2 знака после запятой (округление до копеек) и дописывая нули при необходимости (например, `25.5` выведет как `25.50`).
