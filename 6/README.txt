ЛАБОРАТОРНАЯ РАБОТА № 6
Списки и обработка наборов данных

Файлы:
1. statistics.py — количество, сумма, минимум, максимум и среднее.
2. transform.py — новый список, где отрицательные числа заменены модулем.
3. positions.py — все индексы максимального элемента.

Как запускать:
Откройте терминал в этой папке и выполните:
python statistics.py
python transform.py
python positions.py

Примеры проверки:

1) statistics.py
Ввод: 2 0 -5 3
Количество: 4
Сумма: 0
Минимум: -5
Максимум: 3
Среднее: 0.00

Пустой ввод:
Нет данных

2) transform.py
Ввод: -2 0 5 -3
Исходный список: [-2, 0, 5, -3]
Новый список: [2, 0, 5, 3]

Пустой ввод:
Исходный список: []
Новый список: []

3) positions.py
Ввод: 3 7 2 7
Максимум: 7
Индексы максимума: [1, 3]

Пустой ввод:
Нет данных

Основные понятия:
- list — список, упорядоченная изменяемая коллекция.
- split() — разбивает строку по пробельным символам.
- int() — преобразует текст в целое число.
- len() — возвращает количество элементов.
- sum() — вычисляет сумму.
- min() и max() — находят минимальный и максимальный элементы.
- abs(x) — возвращает абсолютное значение числа.
- enumerate(list) — даёт пары (индекс, значение).
- f"{value:.2f}" — выводит число с двумя знаками после запятой.

Особенности:
- В statistics.py пустой ввод проверяется до вычислений min(), max() и среднего.
- В transform.py создаётся новый список; исходный список не меняется.
- В positions.py индексы считаются с нуля, поэтому в списке [3, 7, 2, 7]
  максимумы находятся на индексах 1 и 3.
