Лабораторная работа 7. Функции и автоматические проверки

Файлы:
- functions.py — три функции по условию; они не вызывают input() и print().
- main.py — программа для ввода данных и демонстрации функций.
- test_functions.py — автоматические тесты.

Как запустить:
1. Убедитесь, что установлен Python 3.10 или новее.
2. Откройте терминал в этой папке.
3. Запустите программу: python main.py
4. Запустите тесты: python -m unittest -v

Что делают функции:
- sum_digits(number): берёт модуль числа и складывает его цифры. Для 0 возвращает 0.
- average(numbers): делит сумму элементов на их количество; для пустого списка возвращает None.
  Исходный список не изменяется.
- normalize_text(text): переводит текст в нижний регистр, убирает пробелы по краям
  и заменяет несколько пробельных символов между словами одним пробелом.

В main.py пустой список вводится нажатием Enter на запросе списка чисел.
В таком случае программа выводит «Нет данных» вместо среднего значения.
