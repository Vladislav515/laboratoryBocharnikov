ЛАБОРАТОРНАЯ РАБОТА: ОБРАБОТКА СТРОК В PYTHON

Файлы:
1. normalize.py — удаление лишних пробелов, подсчёт слов и длины строки.
2. palindrome.py — проверка палиндрома без учёта регистра и обычных пробелов.
3. replace.py — замена двоеточий на дефисы и подсчёт замен.
4. variant.py — индивидуальное задание, поддерживаются варианты 1–15.

Как запускать:
Откройте терминал в папке с файлами и выполните:
python normalize.py
python palindrome.py
python replace.py
python variant.py

В variant.py сначала введите номер своего варианта (1–15), затем текст.
Пример контрольной строки:
Анна, армия! Я читаю. Книга, край, рама.

Условия вариантов:
1 — начинается с «а»
2 — заканчивается на «я»
3 — длина не меньше 5
4 — начинается с «к»
5 — заканчивается на «а»
6 — длина равна 4
7 — содержит букву «р»
8 — содержит ровно одну букву «а»
9 — не содержит букву «а»
10 — начинается и заканчивается одной буквой
11 — длина от 3 до 5 включительно
12 — содержит подстроку «ра»
13 — заканчивается на «й»
14 — длина чётная
15 — начинается с русской гласной

Пояснения:
- Строки в Python неизменяемы: replace(), lower() и strip() возвращают новые строки.
- split() разбивает строку по пробельным символам.
- join() соединяет элементы, вставляя указанный разделитель.
- count() считает неперекрывающиеся вхождения.
- in проверяет наличие подстроки.
- startswith() и endswith() проверяют начало и конец строки.
- Для индивидуального задания пунктуация удаляется только по краям каждого слова
  методом strip(".,!?;:"). Знаки препинания внутри слова не удаляются.
