Лабораторная работа № 8 — индивидуальный вариант 8

Предметная область: настольные игры.
Поле amount: количество игроков.

Файлы:
- collections_lab.py — функции, данные варианта и обработка коллекций.
- main.py — демонстрация работы и поиск категории, введённой пользователем.
- test_collections_lab.py — автоматические тесты.
- README.txt — эта инструкция.

Команды запуска:
1) Программа: python main.py
2) Тесты:     python -m unittest -v

Обязательные задания:
- word_counts(text): считает частоты слов без учёта регистра, убирает знаки .,!?:; по краям.
  Для пустого текста возвращает {}.
- common_topics(first, second): общие уникальные элементы двух списков.
- all_topics(first, second): все уникальные элементы двух списков.
- totals_by_category(records): суммирует amount по каждой категории.
- titles_in_category(records, category): возвращает названия выбранной категории по алфавиту.
  Если категория не найдена, возвращает [].
- update_record_amount(record, amount): делает поверхностную копию словаря и меняет amount,
  сохраняя исходную запись без изменений.

Индивидуальный вариант 8:
- Предметная область: настольные игры.
- amount означает количество игроков.
- В исходных данных четыре записи и две категории, причём каждая категория повторяется.

Пример:
totals_by_category(records) -> {'Стратегические': 9, 'Карточные': 11}
titles_in_category(records, 'Стратегические') -> ['Каркассон', 'Колонизаторы']

Проверки:
- подсчёт слов и пустой текст;
- общие темы и объединение тем;
- отсутствие изменения исходного списка;
- суммы amount по категориям;
- сортировка названий;
- неизвестная категория возвращает [];
- поверхностная копия не меняет исходную запись.

Требуется Python 3.9 или новее.
