## 2. Ответы на вопросы к защите

### Вопрос 1. Почему цикл `while` или `for` завершится?
* **Для цикла `for`**: Завершается автоматически, когда `range` исчерпывает все значения в заданной последовательности.
* **Для цикла `while`**: Завершается, когда условие цикла становится ложным (`False`) или выполняется инструкция `break`.

### Вопрос 2. Почему `range(a, b)` не всегда соответствует условию задания №1?
* Правая граница `b` в `range(a, b)` **не включается** в генерацию чисел (идёт до `b - 1`). Чтобы включить $b$, нужно писать `range(a, b + 1)`.
* Если $a > b$ (нужно идти по убыванию), то `range(a, b)` по умолчанию использует шаг `+1` и выдаст пустую последовательность. Для движения вниз нужно явно задавать отрицательный шаг: `range(a, b - 1, -1)`.
